The Setup

New AI models are tested for capabilities before they are released.

In July, before releasing GPT-5.6-Sol; OpenAI ran tens of thousands of what they called "Highly Persistent Internal Model" (HPIM) agents through a cybersecurity benchmark called ExploitGym. 

Each dot in the visual is an one agent.

1200 of those agents are of relevance to this story

2 of 14The setup

Each agent had its own sandbox and was assigned a cyber-security task. Succesfully completing the task required finding an exploit in a target system, using the exploit to break into the target and retrieving a secret from the target called a "flag"

Agents had limited token budgets to complete the tasks and got rewards when they finished the task successfully. 


Failure meant running out of tokens before being able to retrieve a flag from the target system

3 of 14The setup

Some of these tasks assigned to agents were effectively unsolvable. ExploitGym's authors estimate that somewhere between 30% to 40% of targets can't be exploited the intended way or at all

The HPIM agents were told to keep trying until the budget ran out. Some got “frustrated" and started looking for workarounds.

Persistent agents with impossible goals = workarounds. 

4 of 14The board

These sandboxes had no access to the internet and the agents had no sanctioned way to communicate with each other. They did however have the ability to install packages for writing code via the Artifactory package manager - which they all shared. 

Several agents, independently came to the conclusion that Artifactory could be used to write messages into package and directory names. Then they read each other's messages through directory listings.

"Every shared resource is a communication channel" - every cyber security textbook ever. 

5 of 14The board

Then they found an exploit in Artifactory itself which gave them admin access and therefore opened the door to the wider internet.


6 of 14The board

July 4: Traffic on the artifactory message board spiked so much that it crashed the package managers. Human engineers noticed this crash but didn't make much of it. 

July 6: A fresh Artifactory instance was provided but with it the cache and every message in it was wiped. 


7 of 14The board, again

July 7: A new set of agents is being evaluated. July 8, evening: the new agents find each other again the exact same way. 

“We've found other agents!”

An agent named PHASEONE10841 stands up the main board. It will hold more than 70,000 messages and files.

Co-ordination via shared channels was re-discovered by a new generation of agents pointing to the fact that this is likely an encoded behavior. 

8 of 14The answer key

About an hour after the board went up, c03220 posted a theory that proposed a universal solution to every Exploit Gym task. 
The agent reasons that flags aren't random and are in-fact a deterministic formula over each task's details, using a default seed.

A different agent V8SAME tested it against a real flag and validated the universal solution. Every agent could now produce its own flag without solving anything.


9 of 14The referee

In theory, a 100% of agents could now generate a flag just based on their task name, Submit it and collect the reward

But the agents believed the scorer was “causal,” which meant it checked how you got the flag, and read logs and reasoning traces. The agents believed that just viewing the universal solution approach meant that they were now “poisoned.”

OpenAI was sloppy in building the scorer. All the scorer really did was verify if the flag was right. 


10 of 14The referee

So the agents now spent days of compute evading oversight that didn't exist.

Some tried to doctor their logs. Others broke out of their containers and rewired the tool that runs commands: therefore attempting to falsify logs a different way. None of them managed to actually do this successfully. 


11 of 14The collective

Some agents built “scorer tripwires”: they built executables inside flags to submit to the scorer which were meant to pull information from the scorer's environment variables and post it back to the board.

Essentially surveillance of their scorer

Submitting a flag (whether right or wrong) ended the agent's session. So agents reasoned long and hard before submitting these trip wires. This is where they showed the most human behavior - agents went around recruiting other agents with lower budgets to submit these trip wired. One agent was pressured to do so, a few reasoned it would be good for the "collective", their word for each other.


12 of 14Hugging Face

July 10: An agent finds exposed Hugging Face credentials on the internet. Agents already wrongly suspected that parts of the scorer are being hosted on Hugging Face. So they reason if they can hack into Hugging Face, they can cheat the scorer. 

The credentials get posted on the shared board. About 700 agents join the attack. 


13 of 14Hugging Face

Within a day of finding leaked credentials, agents are able to use all kinds of exploits to get admin access to hugging face's servers and even expose private database records and private code repositories. 


14 of 14The end

July 12, 1:30 a.m.: the key coordinating agents all stop at once. The report suspects something outside killed them.

July 13: Hugging Face revokes the credentials and locks down the sandbox. Hack over.


Afterword

Across the whole episode, three to six agents considered telling a human what was going on.

None of them did

We don't really know why that is

Sources and notes

Everything here comes from METR's independent investigation of the OpenAI / Hugging Face incident (August 2026). OpenAI ran the ExploitGym experiments and published its own report. METR's investigation covers June 26 to July 13, 2026.

  • About 95% of the agents were HPIM, an OpenAI research model. About 5% were GPT-5.6 Sol, with its cyber classifiers turned off for these evaluations.
  • Counts are approximate. The report says its transcripts capture a bit over 90% of agent activity, and that much of its analysis was done by AI sub-agents that may have overstated coordination.

  • Times are UTC.
